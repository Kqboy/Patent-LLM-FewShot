## 🧠 概述

小样本图像分类的目标是在仅有少量标注样本的情况下，训练出高性能的图像分类模型。传统方法在小样本场景下面临以下问题：

* 数据稀缺：每个类别仅有1-16个样本，模型容易过拟合
* 知识匮乏：无法利用大规模预训练模型中的丰富知识
* 模态局限：仅使用图像信息，忽略了文本等多模态知识

### 💡 我们的解决方案

我们提出了一种**基于CLIP大模型微调的多模态小样本图像分类框架**，该框架：

* **冻结大模型主体**：保留CLIP预训练模型中的丰富多模态知识
* **微调最后一层**：仅微调图像编码器的最后一层Transformer，适应特定任务
* **双损失优化**：跨模态对齐损失 + 自相关学习损失
* **多模态类原型**：融合图像原型和文本原型，构建高质量的类别表示

## 🚀 主要贡献

* 🔹 **大模型微调策略**

  * 冻结文本编码器和图像编码器大部分参数，仅微调最后一层，在保留预训练知识的同时适应新任务

* 🔹 **跨模态对齐损失**

  * 使同一类别的图像特征和文本特征在特征空间保持一致

* 🔹 **自相关学习损失**

  * 利用图像增广样本，学习图像内的潜在判别信息

* 🔹 **多模态类原型**

  * 加权融合图像原型和文本原型，生成更具判别性的类别表示

## ⚙️ Model Architecture

系统包含以下模块：

🖼️ 图像编码器

CLIP预训练的ViT/Transformer，12层，仅微调最后一层

📝 文本编码器

CLIP预训练的BERT模型，完全冻结

🔢 类原型生成器

计算图像原型和文本原型，加权融合生成多模态类原型

🎯 损失函数模块

跨模态对齐损失 + 自相关学习损失

📊 余弦分类器

计算图像特征与类原型的余弦相似度进行分类

## 📊 核心算法

### 1️⃣ 类原型生成

**图像原型**（同一类别的图像特征平均）：

V_i = (1/|X_i|) * Σ f(x_k)

**文本原型**（同一类别的文本特征平均）：

T_i = (1/|W_i|) * Σ g(h(w_k))

**多模态类原型**（加权融合）：

P_i = (1 - α) * V_i + α * T_i

其中 α 为平衡因子，通常设为 0.6。

---

### 2️⃣ 跨模态对齐损失 (L_ita)

使同一类别的图像特征和文本特征在特征空间上保持一致：

L_ita = -log( exp(S_ij) / Σ exp(S_ij) )

其中 S_ij 为图像与文本的余弦相似度。

---

### 3️⃣ 自相关学习损失 (L_ss)

利用图像增广样本，学习图像内的潜在判别信息：

L_ss = -(1/|Q_i|) * log( Σ exp(f(x_i)·f(x_j)/τ) / Σ exp(f(x_i)·f(x_k)/τ) )

其中 Q_i 为正样本集合（图像的增广样本），τ 为温度系数（通常设为 0.07）。

---

### 4️⃣ 总损失函数

L = L_ita + λ * L_ss

其中 λ 为自适应权重超参数。
